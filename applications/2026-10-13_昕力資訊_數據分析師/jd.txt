【數據分析師夥伴工作內容會包含什麼？】
1. 負責業務數據的挖掘與分析，定義關鍵指標（KPI），從數據中找出趨勢與潛在商業機會
2. 撰寫高效且準確的 SQL 查詢，進行跨資料表關聯分析，快速支援各部門的臨時數據需求（Ad-hoc query）
3. 使用 Power BI 進行商業報表開發與互動式儀表板設計，將複雜數據視覺化，協助管理層與業務團隊掌握營運狀況
4. 使用 Python 進行探索性資料分析（EDA）、統計分析或資料處理，推動數據分析流程自動化
5. 與業務、產品或營運團隊緊密合作，深入理解業務痛點，並將業務需求轉化為具體的數據分析解決方案與策略建議
6. 定期提供數據分析報告，解讀數據背後的商業意義，用數據說故事以支援公司營運與產品優化決策


【我們希望您具備的技能】
1. 熟悉 SQL，具備撰寫、篩選與關聯複雜資料表的實務經驗
2. 熟悉 Power BI，具備良好的資料視覺化審美，以及商務儀表板開發經驗
3. 具備 Python 基礎（如 Pandas、NumPy），能獨立進行探索性資料分析或自動化報表處理
4. 具備良好的商業敏銳度與邏輯思考，能將抽象的業務問題轉化為可衡量的數據指標
5. 具備出色的溝通與簡報能力，能向非技術背景的團隊清晰闡述數據洞察


加分條件：
1. 有實際商業報表、經營管理報表或電商/產品數據分析的實務經驗
2. 熟悉進階統計方法（如 A/B Testing、迴歸分析、集群分析）並能應用於實際業務場景
3. 具備大數據工具或雲端資料倉儲（如 Google BigQuery、Snowflake）的使用經驗
4. 曾主導過數據專案，並成功透過數據分析為公司帶來流程優化或業績增長


【我們期望您擁有的特質】
1. 對數據與商業趨勢充滿好奇心，能主動從數字中發掘問題與機會點
2. 具備嚴謹的邏輯思維與批判性思考，重視數據來源的正確性與脈絡
3. 具備同理心與傾聽能力，能站在商務單位的視角思考數據價值
4. 重視團隊合作，具備良好的抗壓性與解決未知問題的韌性
